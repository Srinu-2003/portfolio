+ Add a document (no limit — add as many as you want)

There's no cap here — submit this form as many times as you need, whenever a new document comes up, and each one gets its own row underneath the fixed list above. This only adds the row you see here — it doesn't upload anything. Put the actual file in assets/private/ with the file name you type above, and this link will work. Rows you add here are remembered on this browser only (not visible to other visitors, and not synced anywhere) — edit documents.html directly instead if you want a row everyone who unlocks the page will see.

Aadhaar, PAN, and passport are worth protecting harder than the rest — if that link ever leaked, it's identity-theft material, not just an inconvenience. Consider password-protecting those three PDFs individually (real encryption on the file itself) rather than relying on this login screen alone. See the README.
